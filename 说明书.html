① 快速开始（三条）

  1. 解压整个文件夹到任意位置（桌面、U 盘都行），不要只拷一个 html——图片、视频、沉浸式页都在同级的 assets\ 与 scroll-tour\ 里。
  2. 双击 500t门机交互科普页.html，用 Chrome 或 Edge 打开。首次进入建议允许显卡加速，3D 区才能显示。
  3. 要演示「手机第一人称取景」，在文件夹里起一个本地服务（见第 ⑤ 节），手机连同一个 Wi‑Fi 扫码进入。
别用微信/QQ 内置浏览器打开。内置浏览器对 WebGL 与本地文件限制较多，建模台、导演台、手机取景可能只显示降级提示。请用系统 Chrome / Edge。

③ 模块怎么用

深度探索 · PART 01–07

按「先看整机 → 再拆部件 → 最后看作业」的顺序。点部件热区会拉近相机并弹出该部件的说明卡。

科普 · 二级内容

吊具、起升、行走、电气、安全五类知识卡，跟在深度探索后面，读完可回到整机视角。

客户自建建模台 · PART 08

拖滑块改主梁形式、跨度、起升高度、颜色、吊钩/司机室/爬梯，右侧实时重建白模；「保存当前视角」记录机位。

毛毡工坊

上传照片或选示例，点生成走照片模型改成 3D 毛毡手办风；生成历史保留最近 10 张（刷新后仍保留最近的联网生成图 8 张，存在浏览器本地）。

大开眼界导演台 · PART 09

场景盒、角色 A–F、机位小窗、四段时间轴、录制与导出。详见第 ④ 节。

沉浸式穿越页

滚动驱动六段运镜，左下角「‹ 返回主页面」可回。视频较大，机械硬盘首次加载会等几秒。

④ 导演台、白模与运镜

4.1 界面

  • 场景区：门机白模 + 码头作业面（集装箱堆、集卡、灯杆、仓库、岸线），空间盒 60 × 40 × 32 m（示例值）。
  • 镜头小窗：当前机位实时画面，拖动主视图可以改机位，小窗跟着变。
  • 角色：A 主角 / B 司索工 / C 安全员 / D 卡车司机 / E 记录员 / F 巡检员，可在对话里改位置。

4.2 四个常用动作

  1. 摆机位：主视图里拖动旋转、滚轮推拉，或用 W A S D 平移、Q E 升降。
  2. 一键环绕：点工具栏「环绕」，自动生成 10 秒 / 240 帧绕门机一圈（同时缓慢升高）的机位，点「播放」即预演。
  3. 录制 / 播放：点「开始录制」生成一条 10 秒机位；「播放」从头跑一遍；「停止」中断。
  4. 导出参考套件：把机位、角色走位、时间轴导出成给视频模型/Blender 用的参考文件。

4.3 白模怎么来的

Blender 5.x 无头模式跑 模型源文件\build_director_crane.py，按米制参数化建出 73 个对象（轨道、车轮、台车、支腿、上下横梁、双主梁、端梁、小车、机房、起升绳、吊具、司机室、爬梯），导出 director_crane.glb。脚本里改 SPAN / HEIGHT / DEPTH / RAIL_L 就能改尺寸，重新导出后用同样方式内联即可。

注意：导出的 GLB 是 Blender 的 Z 轴向上坐标，进 three.js 时必须 inner.rotation.x = Math.PI/2 立起来，否则整台门机会「躺」在地上，看起来只剩一排横梁。

⑤ 手机第一人称取景

  1. 在本文件夹地址栏输入 cmd 回车，执行：
    python -m http.server 8000
  2. 查电脑内网 IP：ipconfig，找「IPv4 地址」，例如 192.168.1.23。
  3. 电脑上打开 http://127.0.0.1:8000/500t门机交互科普页.html，点导演台工具栏「手机取景」，弹出二维码。
  4. 手机连同一个 Wi‑Fi，扫码或手输 http://192.168.1.23:8000/500t门机交互科普页.html#phone。
  5. 手机里单指拖动转头、上下拖动俯仰、双指捏合改视野。录一段后点「导出取景」，把 JSON 发回电脑，在导演台「导入取景」回放。
为什么不能直接双击？file:// 下浏览器不允许页面读取本地文件、也不允许手机跨设备访问。必须用上面的本地服务（不需要联网，只需要同一局域网）。

⑥ 联网能力与密钥

能力说明
对话建模（LLM）DeepSeek V4.1（模型名 deepseek-v4.1-flash，OpenAI 兼容网关 https://www.aicost.me/v1）。说「作业面改成 80×50×35，机位压低」这类话，页面会解析成参数并重建白模。
毛毡（照片）走 /v1/images/edits 的 gpt-image-2，把上传照片改成 3D 毛毡手办风。需要联网。

密钥已内置在页面里，带不带 sky: 前缀都能直接跑（页面会自动去掉前缀）。如果换了 key：

1) 打开浏览器控制台（F12）
2) localStorage.setItem('crane-llm-key', 'sky:sk-你的新key')
3) 刷新页面
这把 key 会跟着文件走。对外发版、上传公开仓库或交给客户前，建议把页面里的 key 清空、改成服务端代理，避免额度被别人用掉。

⑦ 目前还不行（如实说明）

视频模型 / 毛毡视频：暂未接通。
  • 毛毡的「视频」标签目前是前端滤镜模拟（降采样色块 + 绒面 + 暖调），不是真的视频生成模型，画质和稳定性都有限。
  • 视频生成模型（MiniMax H3 一类）需要单独的 API key 与计费账号，本包里没有配置，所以「用视频模型改视频」这条链路跑不通。
  • 毛毡的「图片」标签是真的照片模型改图，可用，但依赖外网 aicost.me，断网会失败。
  • 页面里的价格、吨位以外的参数均为示例/推定值，正式对外需按铭牌与图纸校准。
  • 拍照识别部件是前端演示逻辑，不是真实视觉模型。
  • 白模为「按白膜图参数化建模」，尺寸是推定值，不代表最终工程设计。

⑧ 常见问题

打开后 3D 区显示「当前运行环境未启用 3D（WebGL）」

浏览器禁用了硬件加速，或显卡驱动过旧。Chrome 设置 → 系统 → 打开「使用图形加速」，重启浏览器；远程桌面/虚拟机里常这样，换本机演示。

图片裂了 / 视频不播

说明 assets\、scroll-tour\ 没跟着一起拷，或文件名被改过。保持目录结构和文件名不变。

手机扫码打不开

三个原因按顺序排：① 没起 python -m http.server；② 手机和电脑不在同一 Wi‑Fi（访客网络/公司网常隔离）；③ Windows 防火墙拦了 8000 端口，允许一次即可。

毛毡生成失败 / 一直转圈

先确认能上外网；再看 F12 控制台是不是 401（key 失效）或 429（额度/频率限制）。图片模式对网络要求比视频模式高。

换电脑后对话建模没反应

检查是否能访问 https://www.aicost.me；公司网络可能拦截。也可在控制台看 fetch 报错。
